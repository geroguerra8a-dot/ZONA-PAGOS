# Diagnóstico Estratégico y Propuesta de Transformación con IA
## Caso: Zona Virtual S.A. (Zonapagos) · Por Impulso IA

Este repositorio contiene el análisis a fondo, diagnóstico operativo, simulador de retorno de inversión (ROI), herramienta de autodiagnóstico interactiva y pitch deck ejecutivo desarrollados por **Impulso IA** (`immpulso.dev`) para **Zona Virtual S.A. / Zonapagos**.

---

## 🚀 Despliegue en Vivo y Uso

1. **Visualización Directa:**  
   Abra `index.html` en cualquier navegador moderno. No requiere dependencias de backend ni pasos de compilación.
2. **Despliegue Inmediato en Vercel:**  
   Conecte este repositorio en [Vercel](https://vercel.com/) o utilice Vercel CLI. El archivo `vercel.json` ya está configurado para despliegue estático de alto rendimiento.
3. **Dossier Maestro en Markdown:**  
   Consulte [`DIAGNOSTICO_Y_PLAN_IMPULSO_IA_ZONAPAGOS.md`](./DIAGNOSTICO_Y_PLAN_IMPULSO_IA_ZONAPAGOS.md) para acceder al sustento documental completo de más de 400 líneas.

---

## 📌 Estructura del Proyecto

* **`index.html`**: Aplicación web ejecutiva responsive construida con Tailwind CSS, Chart.js y Lucide Icons, con tres modos de navegación:
  1. **Dossier Completo (5 Pestañas Modulares):** Radiografía corporativa, Áreas clave de IA, Diagnóstico Interno vs. Externo con matriz FODA, Sistema de Planeación en 3 Fases y Calculadora de Impacto/ROI.
  2. **Pitch Deck Ejecutivo (Modo Diapositivas):** 7 diapositivas diseñadas con la identidad visual de Impulso IA para presentar en reuniones de alta gerencia (con soporte de teclado `←` / `→` o barra espaciadora).
  3. **Herramienta de Autodiagnóstico en Vivo:** Cuestionario de madurez operativa de 8 dimensiones que genera dictamen en tiempo real y plan recomendado descargable.
* **`DIAGNOSTICO_Y_PLAN_IMPULSO_IA_ZONAPAGOS.md`**: Respaldo analítico exhaustivo y base conceptual para la consultoría.
* **`vercel.json`**: Parámetros de optimización para Vercel.
* **`Brochure_Immpulso_4_slides.pdf`**: Presentación corporativa original de Impulso IA.

## 🧠 Filosofía Impulso IA

> *"La IA no llega a reemplazar su empresa. Llega a rediseñar cómo trabaja."*  
> **IA · Procesos · Personas**

### Los 3 Caminos (Se pueden combinar):
1. **Capacitar:** Equipos que entienden la IA y la aplican en sus tareas reales. El contenido cambia según edad, habilidad digital, rol y contexto.
2. **Acompañar:** Trabajamos sobre procesos reales hasta dejar capacidad instalada para que el equipo pueda continuar y mejorar de forma autónoma.
3. **Automatizar:** Levantamos el proceso, diseñamos el flujo y construimos soluciones a la medida de la operación.

### Las 3 Zonas Clave para Zonapagos:
* **Zona de Procesos:** DevBot RAG para acelerar la integración de APIs a comercios, auto-conciliación 360° para transacciones huérfanas y agente de atención a pagadores en picos tributarios.
* **Zona Administrativa:** Extractor asistido de pliegos licitatorios GovTech (SECOP), copiloto de evidencias PCI DSS v4.0 y campus interno de IA (Second Brain corporativo).
* **Zona de Marketing:** Prospección B2B hiperpersonalizada para colegios y municipios, fábrica editorial FinTech (Bre-B y 3DS) y score predictivo de retención de cuentas.
